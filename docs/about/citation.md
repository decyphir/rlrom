# Citation

If you use RLRom in academic work, please cite:

> Ana María Gómez-Ruiz, Alexandre Donzé, Thao Dang.
> **RLRom: Monitoring and Training Reinforcement Learning Agents using Signal
> Temporal Logic.** In *Short Paper Proceedings of the 7th International Workshop
> on Artificial Intelligence and Formal Verification, Logic, Automata, and
> Synthesis (OVERLAY 2025)*, CEUR Workshop Proceedings, vol. 4142, pp. 167–172,
> 2025.

```bibtex
@inproceedings{gomez-ruizRLRomMonitoringTraining2025,
  title     = {RLRom: Monitoring and Training Reinforcement Learning Agents using Signal Temporal Logic},
  author    = {G{\'o}mez-Ruiz, Ana Mar{\'i}a and Donz{\'e}, Alexandre and Dang, Thao},
  booktitle = {Short Paper Proceedings of the 7th International Workshop on Artificial Intelligence and Formal Verification, Logic, Automata, and Synthesis (OVERLAY 2025)},
  series    = {CEUR Workshop Proceedings},
  volume    = {4142},
  pages     = {167--172},
  publisher = {CEUR-WS.org},
  year      = {2025},
  url       = {https://ceur-ws.org/Vol-4142/paper18.pdf}
}
```

To reference the software itself, use the version you ran and the repository
URL, e.g. *RLRom 0.3.0*, https://gricad-gitlab.univ-grenoble-alpes.fr/donzeal/rlrom.

If your work builds on the monitoring engine itself, cite
[stlrom](https://github.com/decyphir/stlrom); its repository carries the
reference and the grammar documentation that RLRom specifications follow.

Machine-readable citation metadata is in
[`CITATION.cff`](https://gricad-gitlab.univ-grenoble-alpes.fr/donzeal/rlrom/-/blob/main/CITATION.cff).
